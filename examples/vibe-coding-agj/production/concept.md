# Concept

## Hook (3 opsi)
1. **"Pakai AI buat ngoding, tapi hasilnya malah berantakan?"** ← dipilih (relate, langsung ke masalah)
2. "AI kamu nggak bodoh. Prompt kamu yang bikin bingung."
3. "Stop copas kode AI sebelum nonton ini."

## Storytelling (3 opsi)
1. Masalah → analogi warung → 5 tips bernomor → soft sell → CTA ← dipilih
2. Before/after satu project yang sama
3. POV: "AI-nya kamu" yang dapat prompt asal

## Analogi utama
Prompt asal = pesan ke abang warung "makanan satu" → ya bingung. Batas: analogi hanya untuk *kejelasan instruksi*, bukan kemampuan AI.
Analogi pendukung: minta rencana dulu = cek rute di Maps sebelum jalan.

## Gaya motion
Dark navy tech + aksen brand AGJ (biru, hijau, kuning). Kamera "terbang" antar scene di satu dunia, whip pan antar tips, zoom dip antar babak. Visual menggambarkan makna (nota warung, balok dipecah, rute Maps, saklar autopilot), bukan transkrip.

## Sumber/klaim
Tidak ada klaim angka. Nama file aturan (AGENTS.md, CLAUDE.md, .cursor/rules) adalah konvensi tool AI coding yang umum; di VO disebut umum "file aturan main".
